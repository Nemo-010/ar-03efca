## Build with evidence

Most scholarly APIs provide metadata and citation counts. Scite adds the text and classification around citations, so you can see how later research has evaluated a publication.

| Capability | What it adds | Guide |
| - | - | - |
| **Literature search** | Search publication metadata and full-text citation statements with Boolean queries and more than 25 filters. | [Search](/guides/search) |
| **Smart Citations** | See supporting, contradicting, mentioning, and unclassified citation statements. | [Smart Citations](/guides/smart-citations) |
| **Paper enrichment** | Resolve DOIs and add publication, author, retraction, and citation data to a workflow. | [Papers and Authors](/guides/papers-and-authors) |
| **Evidence datasets** | Search patents, grants, clinical trials, drugs, devices, adverse events, and safety alerts. | [Evidence datasets](/guides/evidence/overview) |
